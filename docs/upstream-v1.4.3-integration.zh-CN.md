## 兼容行为

正常请求遵循上游 v1.4.3：v2 的子会话 ID 与父会话亲和性分别发送；v1 保持旧版请求约定。额外支持读取 `x-opencode-parent-session-id`，优先于旧别名 `x-parent-session-id` 与请求体元数据。

发生匿名会话恢复时，主会话、已有子会话及父会话一起更换。原先相同的字段仍映射到同一个新会话，原先不同的字段仍保持不同；本地请求 ID 与项目保持不变。恢复只作用于该请求的匿名尝试，回退到密钥通道时使用原始请求身份。

匿名会话恢复次数仍最多为 2；两个通道都持续返回 403 时，单出口最多产生 6 次匿名尝试。429 不触发会话轮换，也不会自动切换模型。所有尝试仍共享原有请求超时。

## 验证范围

回归测试覆盖 v2 优先顺序、主/父/子会话恢复、身份关系保持、跨 server key 隔离、官方会话透传、恢复次数上限、原始身份回退、会话日志、三种协议的请求头和 `patch` 工具定义。CI 增加 `go test ./...`。

本地使用 Go 1.24.4，以下检查均通过：

- 全量测试与 `go test -race ./...`，以及 `go vet ./...`。
- Linux 原生构建与 Windows amd64 交叉编译。
- 66 个受 Git 管理的 Go 文件的格式检查（排除被忽略的本地草稿）。
- 15 个 WebUI JavaScript 文件的 ES module 语法检查。
- 容器入口及构建、启停共 4 个 shell 脚本的语法检查。

测试使用模拟上游，不验证真实免费模型当前是否可用；真实可用性仍取决于上游状态。
